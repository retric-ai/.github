# Security policy

Please report vulnerabilities in any `retric-ai` repository **privately**. Do not open a public issue.

- Preferred: use **Report a vulnerability** under the affected repository's **Security** tab (GitHub private vulnerability reporting).
- Or email **contact@retric.ai** with "SECURITY" in the subject.

Include the affected repository and version or commit, reproduction steps, and the impact you expect. You'll get an acknowledgement within 3 business days and a status update within 10. Fixes are released as soon as practical and credited to the reporter unless you'd rather stay anonymous.

Only the latest release of each project receives security fixes.
