# Contributing

Thanks for your interest in improving a Retric project.

1. **Open an issue first** for anything beyond a small fix, so the approach can be agreed before you write code.
2. **Fork, branch and keep changes focused.** One logical change per pull request.
3. **Run the project's checks locally.** Each repository's README lists its lint, test and build commands; CI runs the same ones.
4. **Write commits in [Conventional Commits](https://www.conventionalcommits.org/) style** (`feat:`, `fix:`, `docs:`, `chore:` …).
5. **Fill in the pull request template**, including how you tested the change.

By contributing you agree that your contribution is licensed under the repository's license.

Report security issues privately; see [SECURITY.md](SECURITY.md).
